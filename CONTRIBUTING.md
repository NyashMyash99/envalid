# Contributing

## Issues

### Before opening a new issue

- Use the search tool to check for existing issues or feature requests.
- Use English for all communications.


### Reporting a bug

- Please provide a clear description of your issue and a minimal reproducible code example.
- Include the envalid version (or commit reference), Go version, and operating system.
- Describe the steps to reproduce the bug.


## Pull Requests

Please ensure your pull request meets the following requirements:

- Pull request is open in the `develop` branch.
- Code is written idiomatically.
- Documentation added or modified to cover code changes.
- Documentation is written idiomatically.
- Commit messages meets the [Commit Message Guideline](https://www.conventionalcommits.org).
- Tests are added or modified to cover code changes.
- All existing tests pass.
